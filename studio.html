Como Cadastrar o Feed nas Plataformas

Uma vez publicado o primeiro episódio, copie a URL do Feed RSS () e submeta nas plataformas:

  • Spotify: Acesse podcasters.spotify.com → "Adicionar podcast existente" → Cole o link do RSS.
  • Apple Podcasts: Acesse podcastsconnect.apple.com → Clique em "+" → "Novo programa via RSS" → Cole o link.
  • Amazon Music: Acesse podcasters.amazon.com → Submeta a mesma URL de RSS.

As plataformas atualizarão automaticamente todos os novos episódios assim que você clicar em Publicar aqui no Studio!
